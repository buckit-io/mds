# Buckit Design System (MDS)

React component library for the Buckit Console UI. Forked from the MinIO Design System.

Module consumption: git-pinned from `github.com/buckit-io/mds` by `console/web-app`.

## How to test

1. Run `yarn install` in the repo root
2. Start Storybook: `yarn storybook`

## Build

```sh
yarn build
```

Output: `dist/esm/`
